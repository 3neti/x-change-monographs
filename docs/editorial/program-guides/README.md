# Banking Program Guides

This directory contains the canonical architecture, parity control, and sector implementations for x-change banking Program Guides.

- [Canonical Banking Program Guide](CANONICAL_BANKING_PROGRAM_GUIDE.md) defines the reusable commercial-handbook architecture and agent obligations.
- [Banking Program Guide Parity Checklist](PROGRAM_GUIDE_PARITY_CHECKLIST.md) records mandatory coverage across sector guides.
- [RBAP Digital Banking Program Guide](rbap/rbap-digital-banking-program-guide.md) is the first implementation. Sections 1–7 are editorially complete, locked, and frozen as the canonical narrative. The Executive Summary has a complete draft and remains in editorial review under EDR-012; it must be revalidated before lock after the required appendices are complete. [Edition 1](../../../build/pdf/rbap-digital-banking-program-guide-edition-1.pdf) publishes this first editorial freeze as a self-contained Board paper. Future chapter changes are limited to factual corrections, typographical corrections, whole-manuscript cadence review, and cross-reference updates.
- [Thrift Bank Digital Banking Program Guide](thrift-bank/README.md) is complete under EDR-013 with two canonical publications: the concise [Executive Edition](../../../build/pdf/thrift-bank-digital-banking-program-guide-executive-edition-v1.pdf) and the comprehensive [Institutional Reference Edition](../../../build/pdf/thrift-bank-digital-banking-program-guide-institutional-reference-edition-v1.pdf). Neither supersedes the other. The [Editorial Acceptance](thrift-bank/EDITORIAL_ACCEPTANCE.md) and approved Institutional Study remain authoritative for frozen doctrine; future work proceeds through institution-specific editions.

The Government Depository Banking Program Guide remains anticipated but has not been created.

Program Guides are separate from sector white papers. White papers establish strategic thought leadership; Program Guides explain a program's institutional proposition, operating model, business case, and launch path.

Generated publication files belong under `build/`, not in this directory.
