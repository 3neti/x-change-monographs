# Thrift Bank Digital Banking Program Guide — Canonical Edition Comparison

## Purpose

The Executive Edition and Institutional Reference Edition are separate canonical publications of the same thrift-bank Program Guide. This note prevents either edition from being mistaken for a correction or replacement of the other.

## Edition Roles

| Dimension | Executive Edition | Institutional Reference Edition |
| --- | --- | --- |
| Primary role | Concise Board paper | Comprehensive institutional implementation reference |
| Primary audience | Board and executive leadership | Board, executive leadership, and responsible implementation functions |
| Editorial state | Canonical, locked, and published | Canonical, locked, and published |
| Narrative scope | Executive Summary and Sections 1–7 | Expanded Executive Summary, Sections 1–7, and shared Appendices A–G |
| Explanatory approach | Compressed institutional argument | Developed reasoning, operating perspectives, scenarios, and governance gates |
| Doctrine | Frozen | Inherited without modification |
| Publication artifact | First Edition, Version 1.0 PDF and HTML | First Edition, Version 1.0 PDF and HTML |

## Relationship Between the Editions

The Executive Edition is the appropriate document for concise Board circulation. It states the institutional proposition, boundaries, operating grammar, representative ceremonies, institutional case, and launch path without requiring the reader to study implementation detail.

The Institutional Reference Edition serves a different reading need. It develops the reasoning beneath the same proposition so that executive sponsors and responsible functions can understand why the operating model is governed as described, how the components relate, what each function must observe, and how the institution moves from approval to controlled production.

Neither edition supersedes the other. The Institutional Reference Edition does not reopen the canonical doctrine, alter the architecture, or change the role of the Institutional Study. Both editions remain doctrinally traceable to the same accepted sources.

## Preserved Doctrine

Both editions preserve these propositions:

- the bank remains the protagonist;
- the bank brings the authority and the rails;
- x-change brings the operating grammar;
- the bank-specific driver connects them;
- settlement connectivity is not a banking service;
- banking capability exceeds payment capability;
- the banking service is the product;
- the Pay Code is the credential;
- readiness is an institutional judgment;
- driver certification is not operational readiness; and
- one governed operating Capability supports many banking services.

## Change Rules

Both editions are locked and may be changed only under canonical governance. Any proposed doctrinal change must be evaluated through a new Editorial Decision Record before either edition is revised.

Institution-specific editions inherit from the canonical guide. They may adapt approved institutional context and implementation detail, but they do not derive new doctrine from editorial elaboration in the Expanded Edition.
