# Annex D — Responsibility Matrix

## Purpose and Limitation

This matrix is a sector-level responsibility framework. It is not a legal RACI, procurement allocation, service-level agreement, or statement about a particular institution. Actual responsibility must be established from applicable law, regulation, charter, policy, contract, account structure, operating procedure, and approved implementation design.

## Application Rule

An institution-specific responsibility matrix must replace generic stakeholder classes with actual legal entities and accountable roles. Unresolved authority or responsibility must remain marked **Unknown** or **Institution-Provided** until sufficient evidence exists. Polished prose must not be used to conceal an unallocated duty.
