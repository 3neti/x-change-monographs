- [`CANONICAL_THESIS.md`](CANONICAL_THESIS.md) freezes the propositions governing the manuscript.
- [`thrift-bank-digital-banking-program.md`](thrift-bank-digital-banking-program.md) is the canonical Phase 1 source manuscript.
- [`ARCHITECTURAL_NOTES.md`](ARCHITECTURAL_NOTES.md) records the institution-specific integration model and driver lifecycle.
- [`PARITY_REPORT.md`](PARITY_REPORT.md) reconciles the package with Movement III, the RBAP Program Guide, and Program Guide governance.
- [`metadata.yaml`](metadata.yaml) records identity, status, audience, and source paths.
