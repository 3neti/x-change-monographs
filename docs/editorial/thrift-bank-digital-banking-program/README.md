# Thrift Bank Digital Banking Program

This directory contains the approved Phase 1 editorial study and doctrinal source for the institution-centric Thrift Bank Digital Banking Program.

- [`EDITORIAL_RECONCILIATION.md`](EDITORIAL_RECONCILIATION.md) identifies what remains canonical and what changes from the existing corpus.
- [`CANONICAL_THESIS.md`](CANONICAL_THESIS.md) freezes the propositions governing the manuscript.
- [`thrift-bank-digital-banking-program.md`](thrift-bank-digital-banking-program.md) is the canonical Phase 1 source manuscript.
- [`ARCHITECTURAL_NOTES.md`](ARCHITECTURAL_NOTES.md) records the institution-specific integration model and driver lifecycle.
- [`PARITY_REPORT.md`](PARITY_REPORT.md) reconciles the package with Movement III, the RBAP Program Guide, and Program Guide governance.
- [`metadata.yaml`](metadata.yaml) records identity, status, audience, and source paths.

This package remains separate from the formal [Thrift Bank Digital Banking Program Guide](../program-guides/thrift-bank/thrift-bank-program-guide.md) governed by EDR-005. The Guide implements the frozen seven-section and Appendix A–G architecture without replacing this doctrinal source.
