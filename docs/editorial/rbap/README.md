# Movement II — Modernizing Rural Banks Without Replacing Them

This directory contains the canonical editorial source and metadata for Movement II of The x-change Monographs.

- `00-modernizing-rural-banks.md` is the canonical manuscript.
- `metadata.yaml` records its publication identity, status, audience, source path, and build.

Movement II follows the Founder Memorandum and precedes the institutional white papers for thrift banks and government depository banking.

Generated PDF, DOCX, HTML, and other publication builds belong under `build/`, not in this directory.

The separate implementation handbook is the [RBAP Digital Banking Program Guide](../program-guides/rbap/rbap-digital-banking-program-guide.md). The white paper remains the canonical thought-leadership source and is not replaced by the guide.
