# Institution Edition

Do not create an Institution Edition manuscript in this directory until `../editorial/EDITORIAL_MAPPING.md` is accepted as **Ready for Drafting** or **Ready for Limited Drafting**.

When authorized, the edition must record its canonical lineage and remain governed by `docs/institutions/INSTITUTION_EDITION_STANDARD.md`.

An Institution Edition adapts the canonical Program Guide. It does not create doctrine, establish commercial terms, or authorize implementation.
