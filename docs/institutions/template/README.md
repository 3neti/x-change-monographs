# Institution Repository Template

Copy this directory only after an institution-specific assignment has been authorized.

Do not begin by drafting an Institution Edition. Complete the artifacts in this order:

1. `sources/SOURCE_REGISTER.md`
2. `sources/EVIDENCE_REGISTER.md`
3. `intelligence/INSTITUTION_INTELLIGENCE.md`
4. `analysis/STRATEGIC_GAP_ANALYSIS.md`
5. `editorial/EDITORIAL_MAPPING.md`
6. `edition/` after drafting is authorized
7. `commercial/COMMERCIAL_PROPOSAL.md` after the edition stage permits proposal work
8. `implementation/IMPLEMENTATION_ROADMAP.md` after approved commercial and discovery inputs exist

Update `metadata.yaml` as artifacts advance. Replace bracketed placeholders only with verified or explicitly classified information.

This template inherits the standards in the parent `docs/institutions/` directory. It must not be used to create new canonical doctrine.
