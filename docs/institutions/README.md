# Institution Intelligence

This directory contains the reusable research and editorial framework for institution-specific applications of the canonical x-change banking doctrine.

**Status:** Canonical and locked under EDR-014; final lock confirmed by EDR-015

**Version:** 1.0

Institution work begins with evidence, not writing. The required sequence is:

> Research → Understand → Analyze → Map → Write → Propose → Implement

## Governing documents

- [Editorial Acceptance](EDITORIAL_ACCEPTANCE.md) records the canonical lock, evidence rule, publishing-system relationship, and future-work boundary.
- [Framework metadata](metadata.yaml) records the canonical state, source paths, workflow, and change control.
- [Institution Intelligence Framework](FRAMEWORK.md) defines the complete artifact sequence, decision gates, and governance boundaries.
- [Public Source Policy](PUBLIC_SOURCE_POLICY.md) governs admissible evidence, source quality, attribution, and the distinction between observation, inference, and recommendation.
- [Research Workflow](RESEARCH_WORKFLOW.md) defines the repeatable research process.
- [Institution Intelligence Standard](INSTITUTION_INTELLIGENCE_STANDARD.md) defines the evidence-based institutional report.
- [Strategic Gap Analysis Standard](STRATEGIC_GAP_ANALYSIS_STANDARD.md) compares current institutional evidence with canonical doctrine.
- [Editorial Mapping Standard](EDITORIAL_MAPPING_STANDARD.md) converts approved intelligence and analysis into a writing brief.
- [Institution Edition Standard](INSTITUTION_EDITION_STANDARD.md) governs institution-specific adaptation of a canonical Program Guide.
- [Commercial Proposal Standard](COMMERCIAL_PROPOSAL_STANDARD.md) defines the proposal layer that follows an Institution Edition.
- [Implementation Roadmap Standard](IMPLEMENTATION_ROADMAP_STANDARD.md) defines the conceptual progression from discovery through expansion.

## Template

The [institution template](template/README.md) is the standard scaffold for future institution repositories. Copy it only when an institution-specific assignment has been authorized.
