# VIS-006 — Recipient Choice Within Claim

## Record

- **Class:** Detail composition
- **Status:** Canonical concept
- **Question answered:** How does the recipient choose without creating another process step?
- **Core insight:** One Pay Code supports a bounded choice among available destinations inside Claim, followed by one completion.

## Composition

```text
Claim
  └── present one Pay Code
          └── choose one ──┬── supported destination
                           ├── supported destination
                           └── supported destination
                                      ↓
                                one completion
```

## Source illustrations

- ILL-004 — Claim
- ILL-005 — Recipient Choice

## Semantic icon dependencies

ICN-001 Person, ICN-003 Pay Code, ICN-008 Validation, ICN-009 Choice, ICN-011 Destination, ICN-014 Settlement, and ICN-015 Completion.

## Reading order

1. The recipient presents one Pay Code.
2. A small supported set becomes visible.
3. One destination is selected.
4. Unselected paths recede.
5. One validated completion follows.

## Primary hierarchy

1. Recipient agency.
2. Bounded choice.
3. Singular completion.

## Nested complexity

VIS-006 remains subordinate to Claim whenever it appears with VIS-001. It may be enlarged as a detail, but its framing must continue to identify it as part of Claim.

## Permitted adaptations

- Two or three generic destinations.
- Static selection or progressive reveal.
- Omission of settlement detail in human-first collateral.

## Prohibited mutations

- Choice as a fourth first-level step.
- Unlimited or branded provider walls.
- Simultaneous selected paths.
- Several completions from one Pay Code.
- Absence of validation or applicable conditions by implication.

## Accessibility summary

Inside Claim, the recipient presents one Pay Code, views a bounded set of available supported destinations, chooses one, and proceeds through validation to one completion.

## Validation profile

Required: Caption Test, Doctrine Test, and Memory Test. A viewer must remember Choice as part of Claim rather than beside it.
