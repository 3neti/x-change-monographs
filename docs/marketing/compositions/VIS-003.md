# VIS-003 — Everyday Applications

## Record

- **Class:** Supporting composition
- **Status:** Canonical concept
- **Question answered:** Where could the same Pay Code journey be applied in everyday institutional activity?
- **Core insight:** Different purposes can reuse one stable visual and operating grammar.

## Composition

```text
ILL-007 Payroll            ILL-009 Insurance Claims
ILL-010 Merchant Refunds   ILL-011 Remittance
ILL-013 Loan Proceeds      ILL-014 Incentives

Each: responsible source → Pay Code → intended recipient
```

## Source illustrations

ILL-007, ILL-009, ILL-010, ILL-011, ILL-013, and ILL-014.

## Semantic icon dependencies

ICN-001 Person, ICN-002 Institution, ICN-003 Pay Code, ICN-004 Instruction, ICN-010 Journey, ICN-011 Destination, and ICN-015 Completion.

## Reading order

The scenarios may be scanned rather than read sequentially. Every tile must preserve the same internal order: responsible source, portable credential, intended recipient.

## Primary hierarchy

1. Repeated visual grammar.
2. Distinct institutional purpose cues.
3. Breadth without feature emphasis.

## Nested complexity

Eligibility, approval, validation, and institutional conditions remain within each scenario. They do not become separate explanatory diagrams.

## Permitted adaptations

- Use all six tiles or a representative governed subset.
- Rearrange the grid according to surface and available space.
- Enlarge one scenario only when an approved audience context requires it.

## Prohibited mutations

- Treating examples as current deployment or availability claims.
- Giving each scenario a different Pay Code journey.
- Ranking applications or providers.
- Showing the Pay Code authorizing payroll, claims, loans, or incentives.

## Accessibility summary

Payroll, insurance claims, merchant refunds, remittance, loan proceeds, and incentives each use the same pattern: a responsible institution represents an authorized purpose with a Pay Code that an intended recipient claims through a supported journey.

## Validation profile

Required: Caption Test and Doctrine Test. Apply the Fifteen-Second Test to the complete grid and to any selected subset.
