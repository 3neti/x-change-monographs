# Marketing Publications

Marketing is the governed publication family that introduces x-change and Pay Code to first-time readers through concise, visually led collateral.

Marketing earns attention. It explains one idea quickly, creates curiosity, and directs interested readers toward deeper governed publications. It does not replace Editorial doctrine, Commercial terms, Experiential demonstrations, Submission Portfolios, or Correspondence records.

## Architecture state

Milestones 1 through 6.1 are approved and the Marketing Design System architecture is frozen. Prototype history is preserved. The active workstream is real reader evidence collection; no production visual identity has been selected.

The prepared first study is [RV-001 — General Unfamiliar Readers](reader-studies/RV-001/MANIFEST.md). It cannot begin until its operational launch gate is completed and precommitted.

## Canonical message

> Send a Pay Code. The recipient chooses where to receive.

Supporting line: **No bank account, e-wallet, or provider details needed upfront.**

This public message is subordinate to the canonical operating boundary: the Pay Code represents an authorized instruction, does not hold money, and is completed only through supported, governed channels and participating financial providers.

Markdown and YAML remain canonical. Rendered PDF, HTML, SVG, presentation, web, print, and social assets belong under `build/` and do not replace these sources.
