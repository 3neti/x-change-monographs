# Visual Sprint Zero — Canonical Pay Code Object

## Status

Non-production visual exploration. No production identity has been selected.

## Purpose

Visual Sprint Zero persists six treatments of canonical VIS-001 after the accepted clarification that Pay Code's visual identity is its framed, human-readable alphanumeric credential—not QR.

The sprint does not reopen the Marketing Design System architecture. It does not replace, modify, or enter RV-001. Milestone 5 and 5.1 assets remain unchanged as historical studies.

## Canonical invariant

```text
|| 7K9M-4R2P ||
```

`7K9M-4R2P` is an illustrative, non-functional value used consistently in these studies. The visible code and its parallel-line framing persist through Generate, Share, and Claim. QR may appear only as a smaller optional encoding or channel cue.
