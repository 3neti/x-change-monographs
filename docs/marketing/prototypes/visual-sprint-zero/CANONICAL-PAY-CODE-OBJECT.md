## Required appearance

The object contains a visible uppercase alphanumeric value framed by two parallel-line marks on each side:

```text
|| 7K9M-4R2P ||
```

The parallel marks belong to the credential identity. They are not pause symbols, money rails, or decorative brackets. The illustrative value is not an active credential.

## Persistence

The code value, grouping, and framing remain recognizable across Generate, Share, and Claim. Position, contrast, and scale may change to show motion or arrival; identity may not.

## QR relationship

QR is optional and secondary. It may encode or help present the same credential, or appear as one sharing cue among SMS, chat, email, print, and voice. It cannot replace the visible code, become larger, or imply that scanning is required.

## Accessibility

Accessible descriptions identify the object as an illustrative, human-readable Pay Code credential. They do not read the sample as live or describe the object as money.

## Promotion boundary

This object study governs Visual Sprint Zero prototypes only. Promotion into a production asset library requires validation, a governed asset record, and an explicit decision.
