# Marketing Visual Prototypes

This area contains noncanonical visual studies used to test whether governed marketing semantics survive different visual treatments.

Prototype work may explore style, hierarchy, and medium. It may not redefine canonical concepts, semantic icons, illustrations, compositions, doctrine, or publication copy.

## Prototype milestones

- [Milestone 5 — VIS-001 Visual Prototype Exploration](milestone-5/README.md)

## Governance

- Prototype Markdown belongs under `docs/marketing/prototypes/`.
- Rough visual assets belong under `assets/marketing/prototypes/`.
- Prototype assets must be labeled non-production.
- Prototype IDs do not become canonical illustration or composition IDs.
- No prototype may be referenced as an approved or frozen asset.
- A prototype advances only through recorded comprehension, doctrine, accessibility, and surface review.

Canonical sources remain authoritative. When a prototype conflicts with a canonical source, the prototype is wrong.
