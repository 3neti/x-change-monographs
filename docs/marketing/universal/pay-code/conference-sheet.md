# Pay Code in 30 Seconds

## Send money without asking where they bank.

> **Send a Pay Code. The recipient chooses where to receive.**

No bank account, e-wallet, or provider details needed upfront.

## Generate → Share → Claim

**Generate.** Create the Pay Code.

**Share.** Send it.

**Claim.** The recipient chooses.

**Primary illustration:** `VIS-001 Core Pay Code`

**Alt text:** A Pay Code is generated, shared with the recipient, and claimed through a supported channel where the recipient chooses an available way to receive.

## One workflow is enough to begin

Payroll. Benefits. Claims. Refunds.

Remittance. Assistance. Loan proceeds. Incentives.

**Bring one payment or disbursement workflow.**

> Money should adapt to people. Not the other way around.
