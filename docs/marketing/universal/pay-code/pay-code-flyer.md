# Send money without asking where they bank.

> A Pay Code lets someone receive money without requiring the sender to know their bank account, e-wallet, or financial provider.

## The visual story

**Illustration sequence:** `ILL-001 → ILL-002 → ILL-003 → ILL-005 → ILL-004`

**Alt text:** A sender authorizes an outcome without knowing the recipient's financial destination. A responsible institution represents the instruction as a Pay Code. The sender shares the credential, the recipient selects an available supported destination, required conditions are checked, and a participating financial provider completes the transaction.

### 1. Authorize

The sender or responsible institution defines the outcome.

### 2. Share

The authorized instruction becomes a Pay Code that can be communicated to the recipient.

### 3. Receive

The recipient presents the Pay Code through a supported journey, and a participating financial provider completes the approved transaction.

> **The Pay Code carries the instruction—not the money.**

## Invitation

**See how a Pay Code works.**

Money should adapt to people. Not the other way around.
