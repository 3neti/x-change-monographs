# x-change Demonstrations

This directory governs the experiential publication family of the x-change publishing system.

Demonstration publications allow an executive, customer, regulator, investor, or partner to experience a controlled customer journey without converting the demonstration into a production credential, voucher, coupon, or commercial instrument.

## Publication families

The x-change publishing system now distinguishes three publication families:

1. **Editorial** — institutional doctrine, studies, Program Guides, and institution editions;
2. **Commercial** — proposals, correspondence, and controlled submission records; and
3. **Experiential** — governed demonstration artifacts that allow a reader to experience a defined customer journey.

Markdown remains canonical. Rendered SVG, PNG, PDF, and print assets are generated under `build/` and do not replace the source record.
