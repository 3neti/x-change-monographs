# VIS-001 Milestone 5.1 Corrected Prototype Assets

These files are non-production correction studies derived from the original Milestone 5 exploration.

## Structure

- `d01-control/` — corrected neutral control, label-free variant, and scale previews.
- `d03-transit-map/` — corrected candidate, label-free variant, and scale previews.
- `d04-editorial-line/` — corrected candidate, label-free variant, and scale previews.
- `d05-wayfinding/` — corrected candidate, label-free variant, and scale previews.
- `d06-modular-card/` — corrected candidate, label-free variant, and scale previews.

Each `previews/` directory contains mechanically scaled PNGs:

- `small-card-480x260.png`
- `page-1200x650.png`
- `banner-distance-1800x975.png`

The three sizes preserve one composition. They are testing exports, not independently redesigned layouts.

D01 is optional. A study manifest must precommit whether the control is included and, when included, present it under the same scale and label conditions as the candidates.

Original Milestone 5 assets remain unchanged under `assets/marketing/prototypes/milestone-5/vis-001/`.

No asset in this directory is an approved production illustration or final visual identity.
