# VIS-001 Milestone 5 Prototype Assets

These grayscale SVG files are non-production visual-direction studies.

They test whether the fixed meaning of [VIS-001 — Core Pay Code Journey](../../../../../docs/marketing/compositions/VIS-001.md) survives eight different visual treatments.

The assets are not:

- canonical illustration masters;
- approved brand artwork;
- production publication assets;
- final typography or color decisions; or
- evidence that a direction passed reader testing.

Canonical semantics remain in `docs/marketing/`. Prototype review documentation is under `docs/marketing/prototypes/milestone-5/`.

Do not promote, overwrite, or reuse these assets as production artwork without a later governed selection and approval milestone.
